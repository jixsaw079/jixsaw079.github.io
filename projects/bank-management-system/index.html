Baseline
Menu-driven banking simulation for practising C and function-based structure.

• Create accounts and automatically assign account numbers
• View accounts and check balances
• Deposit and withdraw with basic amount checks
• Transfer funds between different accounts
• Record loans and repay outstanding amounts
• Reject invalid numeric input and unknown account numbers
• Save records to accounts.txt and reload them at startup

Educational simulation — not real banking software.
$ cat implementation_notes.txt
• Storage uses a text file in the program's current working directory.
• Keep accounts.txt in that working directory between runs.
• Account names should not contain the | separator used by the file format.
• The project supports up to 100 accounts and uses float for money values.
• Loan approval is simulated; no real bank or database is connected.
