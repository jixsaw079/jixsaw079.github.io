A terminal-based C program being developed from a course project into a more reliable application. This page records the current direction and planned changes—not a claim that every improvement is finished.

01 / CURRENT SCOPE
BASELINE

What the prototype is for

The project is a menu-driven banking simulation intended to practise C programming and function-based program structure.

  • Deposit and cash-out operations
  • Account-to-account transfer
  • Loan-related operation
  • Terminal-based interaction

This is a learning project, not real banking software. The source code is not linked here yet, so implementation details should be verified against the published repository before being treated as a tested feature list.

NEXT ITERATION

Reliability before features

  1. Persistent storage

    Save and reload records so data survives program restarts.

  2. Input validation

    Reject invalid numbers, malformed input, and unsafe transaction amounts.

  3. Transaction checks

    Prevent invalid transfers and cash-outs, and verify balances before changing them.

  4. Test cases

    Check normal operations, invalid inputs, missing data files, and restart behavior.

02 / ENGINEERING NOTES

How I’ll document the changes

01

Record the baseline

Describe existing behavior before changing the code, so regressions are easier to spot.

02

Change one thing at a time

Keep each improvement small enough to explain during a code review or viva.

03

Verify the result

Document what was tested and what remains incomplete. No test result is claimed until it has been run.

Status: in development. A source-code link and verified test results will be added once the project is published in a repository and those checks have been performed.
